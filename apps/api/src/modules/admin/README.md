# Admin

Phase 7 composes domain-owned administration projections and commands through exported services. All routes require a live MFA-enabled staff session; mutations require CSRF and permitted Origin. No supplier impersonation, commercial editing, role-management mutation or audit-mutation endpoint is exposed.

See `docs/status/PHASE_7_IMPLEMENTATION_GAP_ANALYSIS.md` and `docs/status/DEVELOPMENT_PHASE_7_COMPLETION_REPORT.md` for scope, migration preservation, verification and manual acceptance.
