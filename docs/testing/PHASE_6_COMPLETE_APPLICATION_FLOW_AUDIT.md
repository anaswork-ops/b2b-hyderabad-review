## Regression gaps

Admin initiated suspension/reactivation has no current endpoint; only enforcement of an existing suspended state can be tested in Phase 6. Hajj/Ground use the inventory API while Tourism/Visa use the vertical API. Browser tests use disposable data, never the preserved demo database. Load, external provider delivery, disaster recovery, and production qualification remain Phase 8.
